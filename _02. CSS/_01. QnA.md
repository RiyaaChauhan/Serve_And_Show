# 🎯 CSS Questions & Answers (Complete Guide)

---

## 🔹 1. **Basics of CSS**

### Q1. **What is CSS?**

**Answer:**
CSS stands for **Cascading Style Sheets**. It’s used to control the **style and layout** of HTML elements on a web page — including color, spacing, font, positioning, and responsiveness.

> "Think of HTML as the structure of a building, and CSS as its paint, design, and layout."

---

### Q2. **What are the different types of CSS?**

**Answer:**

1. **Inline CSS** – inside the HTML element (e.g., `<p style="color:red;">`)
2. **Internal CSS** – inside a `<style>` tag in the `<head>`
3. **External CSS** – in a separate `.css` file linked with `<link>`

> "External CSS is preferred for maintainability and separation of concerns."

---

### Q3. **What is the difference between `id` and `class` in CSS?**

**Answer:**

* `id`: Unique, used to target **one element**. Selector is `#idName`
* `class`: Can be reused on **multiple elements**. Selector is `.className`

> "Use `id` for unique sections, and `class` for styling reusable blocks."

---

## 🔹 2. **Selectors & Specificity**

### Q4. **What are CSS selectors?**

**Answer:**
Selectors are patterns used to select and style elements. Examples:

* Element selector: `p`
* Class selector: `.btn`
* ID selector: `#nav`
* Attribute selector: `input[type="text"]`
* Pseudo-classes: `:hover`, `:first-child`
* Pseudo-elements: `::before`, `::after`

> "They allow us to target elements precisely for styling."

---

### Q5. **What is specificity in CSS?**

**Answer:**
Specificity determines **which rule wins** when multiple rules apply. Higher specificity overrides lower ones.

Order (from low to high):

1. Element selector (1 point)
2. Class/pseudo-class/attribute (10 points)
3. ID selector (100 points)
4. Inline style (1000 points)

> "If two rules apply, the one with higher specificity will be used. If equal, the last one wins."

---

### Q6. **What is the `!important` declaration?**

**Answer:**
`!important` overrides all other declarations, regardless of specificity.

Example:

```css
p {
  color: red !important;
}
```

> "Use sparingly — it breaks the natural cascading order and can cause maintenance issues."

---

## 🔹 3. **Box Model & Layout**

### Q7. **What is the CSS box model?**

**Answer:**
Every element is a box, consisting of:

* **Content** – the actual text or image
* **Padding** – space around content
* **Border** – around the padding
* **Margin** – space outside the border

> "Understanding the box model is essential for precise layouts."

---

### Q8. **How do `padding`, `border`, and `margin` work together?**

**Answer:**
They create space **inside and outside** an element:

* Padding pushes **inward**
* Border wraps the padding
* Margin pushes **outward** from the element

> "Margins collapse vertically, but padding doesn’t."

---

### Q9. **What is the difference between `relative`, `absolute`, `fixed`, and `sticky` positioning?**

**Answer:**

* **Relative**: Positioned relative to its normal position
* **Absolute**: Positioned relative to the nearest positioned ancestor
* **Fixed**: Stays fixed on the screen (e.g., sticky navbars)
* **Sticky**: Scrolls until a threshold, then becomes fixed

> "Understanding positioning helps with modals, tooltips, and layouts."

---

### Q10. **What is `z-index` in CSS?**

**Answer:**
`z-index` controls the **stacking order** of overlapping elements. Higher `z-index` means it appears on top.

> "It only works on positioned elements (`relative`, `absolute`, `fixed`, or `sticky`)."

---

## 🔹 4. **Flexbox & Grid**

### Q11. **What is Flexbox and when would you use it?**

**Answer:**
Flexbox is a one-dimensional layout system used to align items **horizontally or vertically**.

Key properties:

* `display: flex;`
* `justify-content`, `align-items`, `flex-direction`

> "Great for navbars, cards, and centering elements."

---

### Q12. **What is CSS Grid and how is it different from Flexbox?**

**Answer:**
Grid is a **two-dimensional** layout system (rows + columns). Flexbox is one-dimensional (either row or column).

Use Grid for **complex page layouts**, and Flexbox for smaller UI components.

---

## 🔹 5. **Responsive Design**

### Q13. **How do you make a website responsive?**

**Answer:**

* Use `viewport` meta tag
* Use **media queries** to adapt layouts
* Use relative units like `%`, `em`, `rem`
* Use flexible layouts like **Flexbox/Grid**

> "Responsive design ensures usability on all screen sizes."

---

### Q14. **What is a media query?**

**Answer:**
A media query applies CSS rules **conditionally** based on device width, height, etc.

Example:

```css
@media (max-width: 768px) {
  .menu {
    display: none;
  }
}
```

> "Use them to create breakpoints for mobile, tablet, desktop views."

---

## 🔹 6. **Animation & Effects**

### Q15. **How do you create transitions and animations in CSS?**

* **Transitions**: Animate change in property

```css
button {
  transition: background-color 0.3s ease;
}
```

* **Animations**: Define keyframes

```css
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}
```

> "Use transitions for hover effects and animations for complex movement."

---

### Q16. **What is the difference between `visibility: hidden;` and `display: none;`?**

**Answer:**

* `visibility: hidden;` hides the element but **keeps its space**.
* `display: none;` **removes the element completely** from layout.

> "Use `display: none` when you don’t want the element to affect layout."

---

## 🔹 7. **Advanced Concepts**

### Q17. **What are pseudo-classes and pseudo-elements?**

**Answer:**

* **Pseudo-class**: Targets state (`:hover`, `:first-child`)
* **Pseudo-element**: Targets parts (`::before`, `::after`)

Example:

```css
button:hover { background: blue; }
p::first-letter { font-size: 2em; }
```

> "They allow for powerful, targeted styling without extra HTML."

---

### Q18. **What is the difference between `em`, `rem`, `px`, `%` units in CSS?**

**Answer:**

* `px`: Fixed pixel size
* `em`: Relative to parent’s font-size
* `rem`: Relative to root element (`html`)
* `%`: Relative to parent dimension

> "Use `rem` for consistent scaling, especially in responsive design."

---

### Q19. **What is inheritance in CSS?**

**Answer:**
Some properties (like `color`, `font-family`) are inherited from parent to child. Others like `margin`, `padding`, `border` are not.

> "You can force inheritance with `inherit`, or reset it using `initial` or `unset`."

---

### Q20. **What are combinators in CSS?**

**Answer:**
Used to combine selectors:

* `A B`: Descendant (any child)
* `A > B`: Direct child
* `A + B`: Adjacent sibling
* `A ~ B`: General sibling

Example:

```css
ul > li { color: red; }
```

> "Combinators make your selectors more powerful and precise."
